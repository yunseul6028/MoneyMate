# MoneyMate — 기능명세서 (MVP)

**배포 URL: https://moneymate-buddy.vercel.app** (로그인 불필요, 링크 접속 즉시 이용)

---

## 1. MVP 구현 범위

**구현하여 실제 동작하는 범위 (배포본에 포함)**
- 대화형 온보딩(이름·이번 달 예산 설정)
- 금융 대시보드(이번 달 지출·남은 예산·다음 카드결제·카테고리별 지출·AI 한 줄 인사이트)
- 이번 달 지출 상세 조회(거래 내역 표)
- 상호명 기반 자동 분류 + '기타' 결제 대화형 분류·개인화 학습
- 친구 정산 netting(내 몫만 지출로 반영, 받은 정산금은 소득 제외)
- 가상 소비 시뮬레이션("사도 될까?")
- 고민함(충동구매 유예 → '아낀 돈' 누적)
- 선제적 개입 메시지(AI가 먼저 말 걸기) + 시간대 인지
- 홈화면 위젯(미리보기 + 설치 킷)

**본 MVP에서 제외(향후 구현 예정)**
- 실 은행/카드 계좌 연동(마이데이터·오픈뱅킹) — *현재는 개인정보 없는 데모 데이터로 시연*
- 사용자 로그인·회원별 계정 분리(현재 단일 공유 데모 계정)
- 실시간 푸시 알림(모바일 네이티브 알림)
- 대화형 메신저(카카오/텔레그램) 채널

| **가상 소비 시뮬레이션** | "N만원 X 사도 될까?" → 남은 생활비·다음 카드값 영향을 계산하고 AI가 설명 | 채팅 | 구현 완료 |
| **고민함(충동구매 유예)** | 5만원↑ 구매 고민 시 '하루 재워두기' → '고민 중' 목록 → 접으면 '아낀 돈' 누적 | 채팅 버튼 + 대시보드 '고민 중' 섹션 | 구현 완료 |
| **선제적 개입(Proactive)** | 소비가 평소보다 튀면 AI가 먼저 말을 검(개입 가치 검증 후에만) | 채팅(진입 시/이벤트 시) | 구현 완료 |
| **시간대 인지** | 과소비가 잦은 시간대(예: 저녁)에 구매를 고민하면 "재워두자"고 유예 제안 | 채팅(시뮬레이션) | 구현 완료 |
| **홈화면 위젯** | '오늘 쓸 수 있는 돈' 위젯 미리보기 + 설치 안내 | `/widget` 페이지 | 구현 완료 |
| **테스트 이벤트(데모)** | 소비 이벤트를 주입해 AI의 선제 반응·대시보드 갱신을 즉시 시연 | 대시보드 '테스트 이벤트' 패널 | 구현 완료 |

## 3. 사용자 이용 흐름 (배포 URL 접속 후)

1. **접속·온보딩** — URL 접속 → (첫 방문) 서비스 소개 → **이름 입력** → **이번 달 예산 입력**(예: 50만원) → 시작.
2. **대시보드 확인** — 이번 달 지출·남은 예산·카테고리별 지출을 한눈에. **'자세히 보기'**로 거래 내역 표 확인.
3. **AI 먼저 말 걸기** — 채팅에 진입하면 MoneyMate가 **먼저 건 메시지**(소비 관찰 코멘트)가 떠 있음.
4. **친구 정산 처리** — 처음 본 송금이 있으면 "이거 친구랑 정산한 거야?" 질문 → **응/아니** + 카테고리 선택 → **내 몫만** 지출로 반영됨.
5. **'기타' 결제 분류** — 규칙으로 못 정한 결제를 "어디에 넣을까?" 물어봄 → 카테고리 선택 시 분류·학습.
6. **소비 시뮬레이션** — 빠른질문 또는 직접 **"20만원 기타 사도 될까?"** → 남은 생활비·카드값 영향 + **[그래도 살래] / [하루 재워둘래]**.
7. **고민함·아낀 돈** — '하루 재워둘래' → 대시보드 **'고민 중'** 에 등장 → **[접을래]** → '아낀 돈' 적립.
8. **위젯** — 상단 **'📱 위젯'** → '오늘 쓸 수 있는 돈' 미리보기·설치 킷.
9. **(선택) 이벤트 시연** — '테스트 이벤트' 패널로 소비 이벤트 주입 → AI 선제 반응·대시보드 갱신 확인.

## 4. AI 및 데이터 처리 방식

**AI가 수행하는 역할 (생성형 AI: Gemini)**
- **대화·코칭**: 질문 의도 이해, 상황별 자연어 설명·선택지 제시(예: "20만원 기타?"에 지갑 사정을 근거로 설명).
- **분류 보조·학습**: 규칙으로 애매한 가맹점 분류(폴백), '기타' 결제 대화형 분류·개인화.
- **자연어 이해**: 온보딩 대화에서 호칭·예산 파악.
- ※ **남은 돈·카드값·정산·예산 등 모든 숫자 계산은 코드(deterministic)가 수행** — LLM에 계산을 시키지 않아 금융 정확성 확보.

**사용 데이터 / 입력·출력**
- *입력 데이터*: 거래 내역(날짜·가맹점·금액·카테고리·결제수단·거래방향), 사용자 프로필(호칭·월 예산), 사용자 채팅 입력.
- *출력 데이터*: 자연어 답변·코칭, 분류 결과, 시뮬레이션 판정, 대시보드/위젯 지표.

**개인정보·민감정보 처리 여부**
- 현재 MVP는 **개인정보 없는 합성/마스킹 데모 데이터**로 동작(실명·계좌번호·주민번호 등 미포함).
- **로그인·개인식별정보를 수집하지 않음.** 실서비스 단계의 마이데이터 연동은 **본인 동의·암호화 전송·최소수집**을 전제로 함.

## 5. MVP 검증 방법

**검증 절차 (심사자가 배포 URL에서 확인)**
1. `https://moneymate-buddy.vercel.app` 접속 → 온보딩(이름·예산) 완료.
2. 대시보드에서 이번 달 지출·남은 예산 확인 → '자세히 보기'로 거래 표 확인.
3. 채팅의 **먼저 건 메시지** 확인 → 친구 정산 질문에 '응/아니' 응답(정산 반영 확인).
4. **"20만원 기타 사도 될까?"** 입력 → 시뮬레이션 결과 + 버튼 노출 확인.
5. **[하루 재워둘래]** → 대시보드 '고민 중' 등장 → **[접을래]** → '아낀 돈' 증가 확인.

**필요 계정 / 샘플 입력값 / 예상 결과**
- *계정*: **불필요**(로그인 없음, URL 접속만으로 이용).
- *샘플 입력*: 예산 "50만원" / 채팅 "20만원 기타 사도 될까?", "구독 뭐뭐 있어?", "이번 달 왜 이렇게 많이 썼지?"
- *예상 결과 예시*:
  - "20만원 기타 사도 될까?" → *남은 생활비·다음 카드값 변화 계산 + "[그래도 살래] / [하루 재워둘래]" 버튼.*
  - "구독 뭐뭐 있어?" → *넷플릭스·유튜브 프리미엄 등 이번 달 구독 목록.*
  - 친구 정산 '응' → *해당 송금이 정산으로 처리되고 지출에서 '내 몫'만 반영.*

**실행 환경 / 브라우저 제한**
- **모바일 웹 최적화** — 모바일 Chrome/Safari 권장. 데스크톱 브라우저에서도 동작하나 화면이 **폰 너비(중앙 정렬)**로 표시되므로, 브라우저를 모바일 크기로 보면 최적.
- 온보딩은 기기별 1회만 노출(브라우저 저장) — **다시 보려면 시크릿(비공개) 탭**으로 접속.

**MVP 단계의 제한사항**
- **단일 공유 데모 계정**: 여러 심사자가 같은 데모 데이터를 보며, 한 명의 정산/고민함 변경이 공유될 수 있음(다중 사용자 분리는 향후).
- **고정 기준일**: 데모 데이터는 기준일(2026-08-15)로 계산 — 실시간 데이터가 아님.
- **실 계좌 미연동**: 마이데이터/오픈뱅킹 대신 합성 데이터로 시연.
- **AI 폴백**: 생성형 AI(Gemini) 쿼터 소진 시 규칙기반 응답으로 자동 전환(대화가 단순해질 수 있음).
- **콜드스타트**: 서버리스 특성상 일정 시간 미사용 후 첫 응답이 1~2초 지연될 수 있음.
